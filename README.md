## 📁 Repository Directory & Experiment Breakdown

### 🔹 Unit I: Core Foundations
* **Ex No. 1: Data Preprocessing**
  * *Purpose:* Imports `StandardScaler` to perform statistical mean-imputation and multi-variable scaling on localized behavioral datasets.
* **Ex No. 2: Dataset Splitting & K-Fold Cross-Validation**
  * *Purpose:* Implements `train_test_split` validation mechanisms alongside 5-Fold `cross_val_score` checks via a `KNeighborsClassifier`.

### 🔹 Unit II: Supervised Algorithms
* **Ex No. 3: Linear Regression Model**
  * *Purpose:* Models numeric linear target trends (`Marks` vs `Hours_Studied`) while returning Mean Squared Error (MSE) evaluations.
* **Ex No. 4: KNN & SVM Classifiers**
  * *Purpose:* Contrasts K-Nearest Neighbors and Support Vector Machines (`SVC(kernel='linear')`) using precision-recall matrix reports.

### 🔹 Unit III: Unsupervised Frameworks
* **Ex No. 5: K-Means Clustering**
  * *Purpose:* Identifies geometric patterns across unlabelled vectors into explicit partitions using optimized centroid locations.
* **Ex No. 6: Hierarchical Clustering**
  * *Purpose:* Performs complete linkage mapping to output Euclidean dendrogram structures using `AgglomerativeClustering`.

### 🔹 Unit IV: Ensemble Methods
* **Ex No. 7: Random Forest Analysis**
  * *Purpose:* Builds an ensemble tree classifier (`n_estimators=100`) to output localized validation metrics.
* **Ex No. 8: Adaptive Boosting (AdaBoost Classifier)**
  * *Purpose:* Employs a sequence-based adaboost pipeline to output real-time metric feature weight maps.

### 🔹 Unit V: Advanced Paradigm Models
* **Ex No. 9: Tabular Q-Learning (RL)**
  * *Purpose:* Writes a matrix-driven temporal-difference reinforcement routine to resolve structural 6-state path rewards (γ=0.8).
* **Ex No. 10: Multi-Layer Perceptron (Deep Learning)**
  * *Purpose:* Builds an interactive, sequential Keras classification network over 50 iterations.
